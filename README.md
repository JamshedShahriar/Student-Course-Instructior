# Student-Course-Instructor

A web-based application designed to manage student course enrollments, instructors, and administrative management efficiently.

## Features
- Student Registration & Login
- Course Management
- Instructor Assignment
- Enrollment System

## Tech Stack
- PHP
- MySQL
- HTML / CSS / JavaScript
